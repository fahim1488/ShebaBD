# ShebaBD Frontend Accessibility & Quality Checklist

- [x] **Contrast Ratios**: Minimum 4.5:1 for normal text across all dark/light modes
- [x] **ARIA Labels**: All interactive buttons, modals, and dropdowns have explicit `aria-label`
- [x] **Keyboard Navigation**: Focus rings enabled on all inputs and interactive cards
- [x] **Screen Reader Support**: Meaningful alt tags for campaign and organization images
